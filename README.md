# 饱和 FCS 材料

本目录仅含题目输入，不含待实现程序。全部材料为本地合成，无真实个人或仪器数据。Python 3.11；若使用列出的库，可执行 `python -m pip install -r requirements.txt`。无需 Docker、账号或网络数据下载。

events.fcs 是 FCS 3.1、little-endian float32、list mode、四通道。通道由 $PnN 匹配，不按数组位置猜测。标记真值非负，plan 的矩阵行是 detector、列是 marker，y=Sx；不要转置。

检测上限是100，达到上限的通道只有下界99.5，不能仍添加100.5的上界。其余观测采用±0.5区间，负读数允许存储但可能与非负物理模型不相容。门是闭区间约束，null 表示无界，子门继承父门。群比例分母为全部可行事件，避免另引入不确定父门分母；不可行事件单独报告。

# satflow：面向饱和荧光的可行性门控分析

`satflow` 实现一个 `analyze` 命令。它不做自动聚类、logicle 变换、细胞类型诊断，也不拟合串色矩阵；只接受给定的 FCS 3.1 四通道 float32 文件与 plan 描述，对**小数据**逐个事件建立联合可行集合并判定闭矩形门。

## 安装与运行

```sh
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pip install six        # fcsparser 0.2.8 未声明的运行期依赖
.venv/bin/python -m satflow analyze \
    --fcs fixtures/events.fcs \
    --plan fixtures/plan.json \
    --outdir out
```

退出码：`0` 正常（允许存在物理不可行事件，它们被单独报告）；`2` 结构性非法输入（错误的 FCS 版本/数据类型/通道、plan 结构错误、门环等）；`1` 其它错误或自检失败。

## 联合可行集合（核心模型）

对每个事件的检测读数 `y`，真实标记向量 `x` 的可行集合是

```
F = { x >= 0 : l <= S x <= u }
```

- 普通检测通道（`y < saturation_value`）：双侧带 `[y - tol, y + tol]`，`tol = absolute_tolerance`（fixture 为 0.5）。
- 饱和通道（`y >= saturation_value`）：**只有下界** `S_i x >= saturation_value - tol`（fixture 为 99.5），不附加任何有限上界。先对饱和值求逆再“加误差条”的做法被明确禁止。
- `x` 的每个分量非负，作为硬物理约束。

所有约束统一写成线性不等式 `A_ub x <= b_ub` 加变量界 `x >= 0`，用 SciPy HiGHS 可行性 LP 求解。可行集合是**联合**的：一个见证向量必须同时满足全部通道行，禁止把各通道独立的上下界拼成并不存在的同一向量。

### 两类失败严格区分

- **结构非法（StructureError，退出码 2）**：FCS 不是 FCS3.1 / 非 float32 / 通道缺失或重名 / `$TOT` 不符 / NaN、plan 矩阵形状或非负性错误、门引用未知标记或父门、父环、继承后门为空等。此时不产出结果。
- **物理不可行（事件状态 `INFEASIBLE`，不丢弃）**：输入结构合法但该事件的联合系统在 `x >= 0` 下无解，例如负读数的上带边小于零。诊断会区分“观测带本身无交集”和“仅在允许负标记时才有解”。不可行事件单列，不计入任何门计数或比例分母。

## 门判定语义

门是标记空间中的**闭矩形**，`null` 边无界；子门与全部祖先门逐标记取最紧边界（闭区间交集）。对每个可行事件，对门区域 `G` 求解联合 LP：

| 判定 | 含义 | 见证 |
| --- | --- | --- |
| `CERTAIN_IN` | 可行集 `F` 完全包含于 `G`（门外 LP 不可行） | 仅门内见证 |
| `CERTAIN_OUT` | `F` 与 `G` 不相交（门内 LP 不可行） | 仅门外见证 |
| `UNCERTAIN` | `F` 跨过门边界 | 同时给出门内、门外两个联合可行见证 |

门外判定通过对每条门约束行分别建立“违反该行至少 ε”的 LP 实现（行取反，`g_k x >= b_k + ε`），保证见证仍是原联合系统的真实点，而不是辅助变量产物。

### 数值容差与闭边界

- `feasibility_tolerance`（fixture 为 1e-7，记 ε）统一用于：LP 违约间隙、独立见证核查的松弛判据。
- 闭边界包含在门内：门内判据为所有门松弛量 `>= -ε`；严格门外要求至少一行松弛量 `<= -ε`。落在边界上的点算门内，不会被误判为门外。
- 每个见证都由**不调用 LP 求解器**的独立 NumPy 复核（非负、联合观测约束、门内/门外关系、逐项松弛量），结果写入 JSON，供另一个程序代入同一 `A_ub, b_ub` 核查。

## 计数与比例

对每扇门汇总：

- 计数确定下界 = `CERTAIN_IN` 数；可能上界 = `CERTAIN_IN + UNCERTAIN` 数。
- 比例范围 = 上述两界除以**全部可行事件数**。不可行事件与求解器错误事件既不进分子也不进分母，绝不使用“不确定父门数量”作分母。
- 父子嵌套与门扩大单调性：门扩大后必入数、可能入数都不会减少；子门的两个计数界都不超过父门。诊断文件内置这两条自检。

## 交付物（outdir）

1. `event-status.csv`：每个原始 DATA 行一行，保留零基原始行号、float32 原始观测、各通道饱和标志、约束行数、不可行原因及每扇门的判定与理由。
2. `gate-counts.json`：每门计数下界/上界、比例范围、有效闭边界与分母说明。
3. `witnesses.json`：完整模型参数、每事件联合系统（`A_ub`/`b_ub` 及逐行人类可读描述）、代表可行点、每门内/外见证及独立复核结果。代表点只是可行集的一个元素，不是“最优补值”，不能冒充全部可行解。
4. `diagnostics.json`：结构校验记录、事件分桶账目（总数恒等式）、见证复核汇总、父子单调性自检、全部不可行事件的观测与诊断。
