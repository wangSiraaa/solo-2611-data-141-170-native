# 四面体通量材料

一阶四面体网格（VTU）的逐材料进出通量审计工具。只读取既有网格与连续节点
向量场，**不生成网格、不解 PDE、不建三维界面、不自动修复**。Python 3.11，
依赖仅 `numpy` 与 `meshio`：

```bash
python -m pip install -r requirements.txt
```

## 运行

```bash
python -m fluxaudit audit fixtures/mesh.vtu --plan fixtures/plan.json --out audit_out
```

成功时退出码 0，输出目录含四份产物；网格含重复单元、零体积单元或非流形面
（>2 单元共面）时退出码 2，**只写 `diagnostics.json`，不产出任何看似成功的
通量结果**，也不会删面或修复后继续。

### 输出

| 文件 | 内容 |
| --- | --- |
| `faces.csv` | 长表，每个面-侧一行；面可经 `face_id` 回查规范顶点、相邻单元、对侧顶点、外向顶点排列、面积、单位/面积加权法向与面通量 |
| `cells.csv` | 每单元：有向体积（允许为负）、绝对体积、恒定散度、散度体积分、四面通量和、闭包残差 |
| `materials.csv` | 每材料：进/出通量、净通量、外边界分量、界面分量、散度体积分与残差（含单位语义） |
| `diagnostics.json` | 单位、容差、结构校验定位、逐材料残差、全域残差、界面抵消与法向反对称证据 |

## 方法与不变量

* **拓扑身份只看节点下标**。面以排序后的节点三元组为规范 key，面 ID 按 key
  字典序分配；绝不按浮点坐标接近合并节点。单元输入顺序、单元内顶点排列改变
  不影响任何几何与通量结论（有测试覆盖，含单 tet 的全部 24 种排列）。
* **外向法向由对侧顶点确定**：面叉积若朝向对侧顶点即翻转，因此负有向体积
  本身不是坏几何，只拒绝真正的零体积单元。
* **材料边界**：同材料内部面标记 `interior`，不计入任何材料边界；材料间
  公共面标记 `interface`，在 `faces.csv` 中保留两行，各自携带本材料外向
  法向与通量，共享同一 `face_id`。全域检查与逐材料检查共用同一面表，
  不存在"所有单元外面直接相加"导致的重复计数。
* **两条独立计算路径**（不是同一面求和换分组名）：
  1. 面路径：叉积几何得面积加权外向法向，线性形函数下面通量取三节点场均值；
  2. 体路径：参考单元 Jacobian 求逆得形函数梯度与单元恒定散度，再乘体积。
  散度定理要求逐单元、逐材料、全域三个层级的两路结果在容差内一致；
  公共界面两侧通量必须抵消、面积加权法向必须严格反向。
* 仅支持直边一阶 tetra 与连续节点向量场；高阶单元、自动修复、大模型压测
  不在范围内。

## 测试

```bash
python -m unittest discover -s tests -v
```

16 个测试覆盖：真实双材料 fixture、顶点/单元打乱等价性、三个负向文件的
拒绝与定位、常量场零净通量、线性场与解析体积分的独立小例（含面级手算值）、
非四面体拒绝、CLI 退出码与产物。合成小网格仅在测试临时目录中生成。
