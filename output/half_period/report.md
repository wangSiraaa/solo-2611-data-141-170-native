# 周期分析报告 — half_period

## 1. 数据与质量校验

- 输入文件：`half_period.csv`，观测点 144 个，观测夜 12 个，时间跨度 T = 11.5282 天。
- 重复 observation_id、非有限数、非正 sigma 检查：均未发现。

## 2. 频率分辨率与网格设计

- Rayleigh 分辨率 1/T = **0.08674 /天**（对应周期方向 0.6808 天量级）。时间跨度决定两个峰至少相差约 1/T 才可能被采样独立分辨；
- 粗网格步长 1/(10T) = 0.008674 /天，共 310 个频率点；每个局部极小再做 3 轮局部细化（每轮 41 点、区间缩至 1/5），候选 JSON 给出各候选最终网格步长；
- 全部计算只在真实观测时刻构建设计矩阵做加权最小二乘，没有把长空白插补成规则序列，也没有使用 FFT。

## 3. 采样窗审计

- 夜间隔：0.907–1.093 天，其中 100% 落在 1±0.15 天；

### 4.3 P 与 2P 的近等价解释

- 候选 0（2P = 2.8015 天）对候选 1（P = 1.3995 天）：χ² = 148.49 vs 158.76（相对差 6.5%），BIC = 29.3 vs 29.0，留出 χ² = 160.9 vs 168.8，长周期模型 A1/A2 = 0.055，判定：**近等价，保留 P 与 2P 两种解释**。

## 5. 结论与可分辨性说明

全数据 χ² 最优候选为 P = 2.8015 天（f = 0.35695 /天，K = 2）。 存在与每日采样有关的别名候选（标注 daily_alias）：谱窗在 ±1/天等处有强旁瓣，这些频率与主频率在当前采样下近线性相关，χ² 接近不代表多个真实周期，需夜内时刻更分散或更长时间跨度才能拆开。 存在 P 与 2P 近等价的候选对：信号近似半周期对称（长周期模型一次谐波很弱），现有采样在两种解释之间无法给出有意义的偏好，两个周期同时保留。 整夜留出中最优候选同样排名第一，与全数据拟合一致。

整夜留出（每折仅用其余 11 夜拟合、预测整条留出夜）与相位折叠 CSV 是支持性证据；有限且带窗的采样不保证恢复唯一真周期。采样或信号形状不足以区分时，本报告保留候选集并给出原因，而不是强制只报一个最高峰。
