# 案例 `outlier` 定位报告

## 数据与模型
- 台站 8 个,pick 16 条(P: 8, S: 8)。
- 模型固定:`arrival = t0 + 欧氏距离 / 相位波速`,波速 P=6.0 km/s, S=3.5 km/s,不反演速度结构。
- 稳健目标:Huber 代价 `C = Σρ(r)`,c = 1.5(以标准化残差为单位);同一代价用于优化与剖面。
- 搜索盒:x∈[-10.0, 10.0], y∈[-10.0, 10.0], depth∈[0.0, 15.0] km,t0∈[-5.0, 5.0] s。

## 解(联合估计 x, y, depth, t0)
- 最优解:x = 1.9478 km,y = 2.9817 km,depth = 5.5383 km,t0 = 1.2817 s,代价 = 85.9926。
- 标准化残差 RMS = 13.5963,最大 |r| = 54.2803。
- 多初值(27 个)局部优化后聚类得到 **1 个不同极小点**;代价 ≤ 最小值 + 4.0 的竞争解:

## 深度可解性与参数补偿
- 局部曲率(仅线性化):参数标准差 x=0.035 km,y=0.041 km,depth=0.245 km,t0=0.018 s;Hessian 条件数 2.7e+03。
- 最弱约束方向 (x, y, depth, t0) ≈ (-0.04, -0.07, -0.99, +0.07);该小椭球只是局部近似,多解检查以上述网格支持区域为准。

## 数值说明
- 网格步长 1.0 km,网格 21×21×16 = 7056 点,每个格点用 IRLS 重估 t0(容差 1e-10 s,实际最多 150 次迭代)。
- 局部优化:scipy.optimize.least_squares (trf, loss=huber, f_scale=1.5, x_scale=jac),收敛容差 1e-12;解聚类半径 0.5 km / 0.5 s。
- 未覆盖区域:搜索盒以外不评估;支持区域范围为体素量化(±0.5 km)。

## 注意事项
- 支持区域(代价 <= 最小值 + delta)只是数值支持区域,不是已校准的置信水平。
- local_curvature 来自最优解处的局部线性化 Hessian,不能替代多解检查;弱几何下它可能给出误导性的小椭球。
- 搜索盒以外区域未覆盖;若支持区域触及边界,盒外延续未知。
- 支持区域范围按 1 个体素量化(±半步长);网格之间的细节由局部优化补充。
- 代价采用 Huber 稳健损失;换用其他损失会改变支持区域口径,比较时需同一代价定义。
