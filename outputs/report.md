# 单事件到时定位总报告

## 方法(三组共用)

- 模型固定:`arrival = t0 + 欧氏距离(源, 台站) / 相位波速`,波速 P=6.0 km/s, S=3.5 km/s;不反演速度结构,各组独立分析。
- 目标函数:Huber 稳健代价 `C = Σρ(r)`,c = 1.5(以标准化残差为单位),对少数误拾取稳健;优化与剖面使用同一代价定义。
- 搜索策略:先在 1.0 km 三维网格上逐点重估 t0 并计算代价,再从各连通块最小点、分散低成本格点、盒中心/台阵中心等多初值做局部优化并聚类,不以单次局部收敛断言唯一解。
- 支持区域:代价 ≤ 最小值 + 4.0 的格点集合,**只是数值支持区域,不是已校准置信水平**。

## 几何与误拾取的影响

### good
- 代表解:(1.950, 3.040, 5.957) km, t0 = 1.253 s;支持区域:x ∈ [2, 2] km,y ∈ [3, 3] km,depth ∈ [6, 6] km。
- 台阵几何充分:多初值搜索仅得 1 个极小点,支持区域收缩到体素级,深度可解(见案例报告的局部曲率,仅为线性化参考)。

### weak
- 代表解:(2.000, -4.491, 4.983) km, t0 = 1.250 s;支持区域:x ∈ [2, 2] km,y ∈ [-7, 7] km,depth ∈ [0, 7] km。
- **多解**:共 12 个等代价/近等代价极小点;台阵近共线且缺少 S 相,y 符号完全不可分辩,depth 与 |y| 沿 y²+depth²≈常数 的弧互相补偿——深度在此几何下不可唯一确定,只能给出支持区域。
- 支持区域内 y²+depth² = 45.29 ± 4.14 km²,depth–|y| 相关 -0.93;t0 在 [1.216, 1.284] s 内仅小幅变化(x 与 t0 仍被走时水平与到时绝对值较好约束)。

### outlier
- 代表解:(1.948, 2.982, 5.538) km, t0 = 1.282 s;支持区域:x ∈ [2, 2] km,y ∈ [3, 3] km,depth ∈ [5, 6] km。
- 稳健降权:outlier-2-P(标准化残差 +54.3, 权重 0.03);仅降权未剔除,全部台站仍参与反演。
- 与 good 案例解相距 0.423 km(同台阵几何,误拾取被降权后解保持稳定;Huber 影响有界但非零,残差仍轻微拉动解)。

## 交付物清单

每个案例目录含:`solution.json`(解/竞争解/支持区域/诊断)、`residuals.csv`(观测、预测、标准化残差、权重)、`profile.csv`(三维网格代价剖面)、`depth_profile.csv`(逐深度最优代价)、`report.md`(案例报告)。

## 注意事项
- 支持区域(代价 <= 最小值 + delta)只是数值支持区域,不是已校准的置信水平。
- local_curvature 来自最优解处的局部线性化 Hessian,不能替代多解检查;弱几何下它可能给出误导性的小椭球。
- 搜索盒以外区域未覆盖;若支持区域触及边界,盒外延续未知。
- 支持区域范围按 1 个体素量化(±半步长);网格之间的细节由局部优化补充。
- 代价采用 Huber 稳健损失;换用其他损失会改变支持区域口径,比较时需同一代价定义。
